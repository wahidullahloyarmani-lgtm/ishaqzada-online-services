# اسحاقزاده آنلاین خدمات — Online Shop

دا د Android او iPhone لپاره د Flutter لومړنی Shop Starter دی.

## شامل امکانات
- لوکس تور/طلایي UI
- پښتو RTL interface
- Home، Categories، Cart، Profile
- Search field
- Product cards او Add to Cart
- د فرمایش لپاره ابتدایي dialog
- د «اسحاقزاده آنلاین خدمات» لوګو

## چلول
1. Flutter نصب کړئ.
2. په دې فولډر کې `flutter pub get` اجرا کړئ.
3. Android لپاره: `flutter run`
4. iPhone لپاره: `flutter run` (په macOS/Xcode کې)

## د بشپړ آنلاین Shop لپاره راتلونکي کارونه
- Firebase Authentication
- Firestore products/orders
- Admin Panel
- Product image upload
- Online payment / Cash on Delivery
- Delivery address
- Push notifications
- App Store / Google Play release
